
# Meu Currículo no GitHub

## Sobre o projeto

Este projeto foi desenvolvido como atividade prática
da faculdade, com o objetivo de aprender a utilizar
Git e GitHub na criação e gerenciamento de projetos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Estrutura do projeto

- index.html: página principal do currículo.
- contato.html: página com informações de contato.
- README.md: documentação do projeto.

## Funcionalidades

- Apresentação pessoal.
- Formação acadêmica.
- Habilidades técnicas.
- Objetivo profissional.
- Página de contato.

## Objetivo

Praticar os conceitos de controle de versão,
criação de branches, commits, push e Pull Requests.
